# Sample Python Project

This project contains a simple Python script, `main.py`, that prints the message "Hello, World!" to the console.

It also includes `snake.py`, a small terminal-based implementation of the classic "Snake" game using the built-in `curses` library.

## How to Run `main.py`

1. Ensure you have Python installed on your system.
2. Open a terminal or command prompt.
3. Navigate to the directory where `main.py` is located.
4. Run the script using the following command:

   ```bash
   python main.py
   ```

This will execute the script, and you should see "Hello, World!" printed to your console.

## How to Play the Snake Game

The snake game requires a terminal that supports `curses` (most Unix-like systems). Run it with:

```bash
python snake.py
```

Use the arrow keys to move the snake. Eat the `*` characters to grow. Avoid running into the walls or the snake's own body. When the game ends, press any key to exit.
